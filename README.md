# Бейджи для README

**225 готовых бейджей** в одном стиле. Это обычные SVG-файлы: они лежат в репозитории, не зависят от shields.io и не ломаются из-за «неизвестных иконок».

## Как пользоваться

1. **Самый удобный способ:** откройте [страницу с галереей](https://bread11yt.github.io/badges/), нажмите на бейдж, и код скопируется в буфер обмена. Вставьте его в свой README.
2. **Через этот README:** найдите бейдж в таблицах ниже и скопируйте его код (в каждой категории есть блок «скопировать всё», у него есть кнопка копирования).
3. **Напрямую:** ссылка на любой бейдж имеет вид `https://raw.githubusercontent.com/Bread11YT/badges/main/badges/КАТЕГОРИЯ/ИМЯ.svg`.

Чтобы бейджи стояли по центру в профиле, оберните их в:

```html
<div align="center">

  <!-- сюда вставьте бейджи -->

</div>
```

Если хотите, чтобы бейдж был ссылкой, оберните его так: `[![Python](ссылка-на-бейдж)](https://python.org)`.

## Добавить свой бейдж

Нужен только Python 3:

```bash
python build.py add "Bun" E8B84A Bn "Веб"
```

Параметры: название, цвет (HEX без `#`), 1-2 буквы для значка, категория и (для новой категории) имя папки латиницей, например `python build.py add "Bun" E8B84A Bn "Веб"`. Скрипт создаст SVG и обновит README и страницу галереи.

Хотите настоящий логотип вместо букв? Откройте `badges.json` и у нужного бейджа замените `"icon": "Py"` на `"svg": "<path d=\"...\"/>"` (содержимое SVG 24×24, без тега `<svg>`), затем запустите `python build.py`. Логотипы можно взять, например, на [simpleicons.org](https://simpleicons.org).

## Настройка

В `badges.json` в начале файла указаны `owner`, `repo` и `branch`. Если вы назвали репозиторий иначе или у вас другое имя пользователя, поменяйте их и запустите `python build.py`: все ссылки в README и на странице обновятся.

Страница-галерея работает через GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / `(root)`*.
